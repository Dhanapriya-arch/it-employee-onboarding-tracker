# IT Employee Onboarding and Account Setup Tracker

A beginner-friendly IT Support portfolio project built with HTML, CSS, and vanilla JavaScript.

## Features
- Add, edit, and delete onboarding records
- Track equipment, account setup, software, and orientation tasks
- Automatically calculate completion percentage
- Dashboard counts for employees and task statuses
- Search and filter records
- Export records to CSV for Excel
- Save changes in browser local storage
- Responsive desktop/mobile layout
- Fictional sample records included

## Run locally
1. Download or clone this repository.
2. Keep `index.html`, `style.css`, and `script.js` in the same folder.
3. Open `index.html` in Edge or Chrome.
4. Test adding, editing, searching, filtering, and exporting records.

## Publish with GitHub Pages
1. Create a public repository named `it-employee-onboarding-tracker`.
2. Upload `index.html`, `style.css`, `script.js`, `README.md`, and `TESTING-CHECKLIST.md`.
3. Open **Settings → Pages**.
4. Select **Deploy from a branch**, branch `main`, folder `/(root)`, then save.
5. Open the URL shown in Pages. It normally follows this format: `https://YOUR-GITHUB-USERNAME.github.io/it-employee-onboarding-tracker/`

## Limitations
This is a front-end demo, not a production HR or identity-management system. It does not create real accounts, assign permissions, connect to a server, or share data between users. Records are stored only in the browser. Never enter real employee information, passwords, or confidential data.

## Skills demonstrated
HTML, CSS, JavaScript, form handling, browser local storage, search/filter, CSV report generation, and IT onboarding workflow documentation.
