# Testing Checklist

- [ ] Open `index.html` in Edge or Chrome.
- [ ] Confirm fictional sample records and dashboard counts appear.
- [ ] Add a fictional employee with a joining date and different task statuses.
- [ ] Confirm the new record appears and dashboard counts update.
- [ ] Click Edit, change a status, and save.
- [ ] Search by employee name or department.
- [ ] Filter by Pending, In Progress, and Completed.
- [ ] Click Export CSV and open the downloaded file in Excel.
- [ ] Refresh and confirm records remain in the same browser.
- [ ] Delete a sample record and confirm it disappears.
- [ ] Check the page at a narrow/mobile width.

Note: local storage is browser/device-specific. This demo does not create real accounts or provision devices. Use fictional data only.
